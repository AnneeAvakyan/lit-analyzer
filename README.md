# lit-analyzer
Litanalyzer - это бэкенд-сервис на Go для автоматического анализа художественных текстов. Пользователь загружает книгу через API, а система разбивает текст на предложения, выделяет имена собственные, отсеивает случайные упоминания по частоте и сохраняет найденных персонажей в PostgreSQL. На выходе получается структурированная картина произведения: список действующих лиц с частотой упоминаний и граф их связей, построенный по совместным появлениям в тексте. Сервис работает в Docker-окружении, использует миграции и слоистую архитектуру с разделением на домен, репозитории и usecase-слой, а извлечение персонажей и сегментация покрыты тестами. Практическая ценность в том, что он избавляет от ручного разбора объёмных текстов и пригодится читателям, преподавателям филологии и учителям литературы, где графы персонажей используются для сравнения произведений и авторских стилей, а также мысленного структурирования сюжета.
